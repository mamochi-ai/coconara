■ 使い始め方（iPad・スマートフォン）
------------------------------------------------
次の購入者用 URL を Safari で開いてください。このZIPのファイルを操作する必要はありません。

  https://mamochi-ai.github.io/coconara/buyer/

1. Safari で上の URL を開きます。
2. 最初に「使い方」の案内が出ます。「新しい注文を始める」を押すと、空の状態から入力できます。
   操作を試したいときは「架空のサンプルで試す」を押します。
3. 次回からも同じ URL を、同じ端末の同じブラウザで開いてください（ブックマークをおすすめします）。

詳しい使い方：https://mamochi-ai.github.io/coconara/manual.html
（このZIPの web/manual.html、single/manual.html も同じ内容です）

※ URL の提供期間は、販売ページの記載に従ってください。
※ この URL を知っている人は、誰でも開くことができます。第三者への共有はご遠慮ください。

パソコンで使う場合は、single/katachi-awase.html をパソコンのブラウザで開くこともできます。
（販売者の確認は、パソコン用ブラウザ Chromium でファイルを直接開いた場合のみです）

iPad の「ファイル」アプリで ZIP を展開して HTML を開く方法は、動作を確認していません。
iPad では上の URL をお使いください。


■ 大切なこと
------------------------------------------------
・入力内容は、使っている端末のブラウザの中だけに保存されます。
  サーバーへの送信や、ほかの端末・ほかのブラウザとの自動同期はしません。
・ブラウザのデータ削除や容量不足などで、保存した内容が消えることがあります。
  「データ」→「バックアップを書き出す」で、定期的にバックアップしてください。
  復元は「データ」→「バックアップから復元」です。
・開く場所（URL やファイル）が変わると、保存場所も別になります。
  移るときはバックアップを書き出して、新しい場所で復元してください。
・体験版（https://mamochi-ai.github.io/coconara/）とは保存場所が別です。体験版の内容は引き継がれません。
・模式図です。型紙・裁断図ではありません。色は目安です。
・持ち手高さは、袋口から持ち手の頂点までの高さです（テープの全長ではありません）。
・底幅（袋口幅 − マチ）は、このツールが対応する船底型トートの場合の関係です。
・「変更前として保存」は、比べる基準の記録です。お客様の承認の記録ではありません。
・オフラインでの利用には対応していません。
・Safari の「ホーム画面に追加」は使えますが、そこから開いた場合の動作と保存場所は確認していません。
  使う場合は、毎回同じ方法（ホーム画面のアイコン、または Safari のブックマーク）で開いてください。
