バッグのサイズや仕様変更を、ひと目で伝わる確認画像に。

■ 使い始め方
------------------------------------------------
使い始め方は、使う端末によって異なります。

(1) 販売者から購入者用の URL を受け取った場合（iPad・スマートフォン向け）
    受け取った URL を Safari などのブラウザで開いてください。
    このZIPのファイルを操作する必要はありません。
    ※ URL の提供方法・提供期間は、販売ページの記載に従ってください。

(2) パソコンで使う場合
    single/katachi-awase.html をパソコンのブラウザ（Chrome、Edge、Safari など）で開きます。
    ※ 販売者の確認は、パソコン用ブラウザ（Chromium）でファイルを直接開いた場合のみです。
       お使いのブラウザによっては、保存やダウンロードが制限されることがあります。

(3) 自分で Web に公開して使う場合（パソコンでの作業が必要です）
    web/ フォルダの中身を、HTTPS で公開できる静的ホスティング
    （GitHub Pages、Netlify など）に置き、公開された URL を開きます。
    サーバー側の処理やデータベースは不要です。

【iPad で ZIP を展開して HTML を開く方法について】
    iPad の「ファイル」アプリで HTML ファイルを開くと、ツールとして動かない場合があります。
    販売者は、この方法での動作を確認していません。iPad では (1) の方法をおすすめします。


■ 大切なこと
------------------------------------------------
・入力内容は、使っている端末のブラウザの中だけに保存されます。
  サーバーへの送信や、ほかの端末との自動同期はしません。
・ブラウザのデータ削除や容量不足などで、保存した内容が消えることがあります。
  「データ」→「バックアップを書き出す」で、こまめにバックアップしてください。
・開く場所（URL やファイル）が変わると、保存場所も別になります。
  移るときはバックアップを書き出して、新しい場所で復元してください。
・模式図です。型紙・裁断図ではありません。色は目安です。
・持ち手高さは、袋口から持ち手の頂点までの高さです（テープの全長ではありません）。
・底幅（袋口幅 − マチ）は、このツールが対応する船底型トートの場合の関係です。
・「変更前として保存」は、比べる基準の記録です。お客様の承認の記録ではありません。
・ホーム画面への追加やオフラインでの利用には対応していません（動作を確認していません）。
