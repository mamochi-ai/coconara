# 配布と公開の手順・配布内容一覧

## 1. 公開の構成

| | 公開体験版 | 購入者用 |
|---|---|---|
| URL | https://mamochi-ai.github.io/coconara/ | https://mamochi-ai.github.io/coconara/buyer/ |
| ファイル | `docs/index.html` | `docs/buyer/index.html`（`npm run build` で `docs/index.html` から生成） |
| 共通で使うもの | `docs/js/`、`docs/css/`、`docs/manual.html`（1つだけ。二重管理しない） | 同左 |
| 版の決まり方 | 印なし → 体験版 | `<meta name="katachi-edition" content="buyer">` → 購入者用 |
| 確認画像 | 上下に「体験版・サンプル」の帯 | 帯なし（サンプル使用中の「架空のサンプルです」表示は残る） |
| 開いたとき | 架空のサンプルを表示 | 保存データがあればそれを表示。なければ空。初回だけ使い方の案内 |
| 保存場所（ブラウザ内） | `katachi-awase:trial:doc` | `katachi-awase:doc` |
| 検索エンジン | 対象 | `noindex, nofollow` を指定（検索結果に出にくくするだけで、非公開にはならない） |

- GitHub Pages は、ブランチ `claude/katachi-awase-bag-tool-c6hlbu` の `/docs` フォルダから公開されています（GitHub Actions の「pages build and deployment」の実行記録で確認）。このブランチにプッシュすると、1分ほどで公開内容が更新されます。
- 体験版のページ・使い方・プログラムから、購入者用ページへのリンクはありません。
- URL パラメーターや画面上の隠しボタンで体験版を解除する仕組みはありません。

## 2. 購入者用について正確に理解しておくこと

- **購入者用 URL は、知っている人なら誰でも開けます。**パスワード・ログインなどの保護はありません。
- **購入者用のプログラムは取得可能です。**公開ページのファイル（`/buyer/index.html`、`/js/*.js` など）は誰でもダウンロードでき、体験版と購入者用の違い（ページの印1行）も読めば分かります。リポジトリ自体は非公開ですが、公開ページの中身は公開されています。
- したがって、URL を限られた人に伝えることは、購入者の認証やコピー防止にはなりません。利用条件（`納品メッセージ_下書き.md` の「ご利用にあたって」）で、共有・再配布を控えていただくようお願いする方式です。
- 購入者用の配布 ZIP は公開対象に含めていません（`build/` は git 管理外。`docs/` に ZIP は置いていません）。

## 3. 購入者への納品

1. `product/納品メッセージ_下書き.md` の【 】を確定して送る（購入者用 URL・使い方・保存とバックアップ・問い合わせ時の情報・利用条件の案を記載済み）。
2. 補助として、配布 ZIP（`build/katachi-awase-buyer-<バージョン>.zip`）を渡す（任意）。

## 4. 更新のしかた（作業者：開発環境を使う人。Claude Code から実行できます）

```
# 1. docs/ のファイルを修正する（docs/buyer/index.html は直接編集しない）
npm run build      # docs/buyer/index.html を作り直し、配布 ZIP を build/ に作る
npm test           # 単体テスト（購入者用ページが最新かも確認）
npm run test:e2e   # ブラウザ操作テスト
# 2. コミットしてブランチにプッシュ → GitHub Pages が自動で更新
```

`node scripts/build.mjs --check` で、`docs/buyer/index.html` が最新かだけを確認できます。

## 5. 配布 ZIP の内容

`build/katachi-awase-buyer-<バージョン>.zip`（バージョンは `package.json` の `version`、現在 0.1.0。販売用の番号は未決定）

| ファイル | 内容 |
|---|---|
| `katachi-awase/README.txt` | はじめにお読みください（購入者用 URL・使い始め方・注意） |
| `katachi-awase/MANIFEST.txt` | 配布内容一覧（各ファイルの大きさと SHA-256） |
| `katachi-awase/web/` | 購入者用 URL と同じ内容（index.html, manual.html, css/, js/） |
| `katachi-awase/single/katachi-awase.html` | 1ファイル版 |
| `katachi-awase/single/manual.html` | 使い方 |

含めていないもの：開発用ファイル（テスト・スクリプト・販売資料）、`.nojekyll`、公開用の `buyer/` ページ、保存データ・お客様のデータ。

| 使い方 | 確認状況 |
|---|---|
| iPad・スマートフォンで購入者用 URL を開く | 公開 URL を Chromium（iPad 相当の画面幅）で開いて確認。iPad 実機は未確認 |
| パソコンで `single/katachi-awase.html` を直接開く | パソコン用ブラウザ Chromium（file://）で確認。Safari・Edge・Windows は未確認 |
| `web/` を自分で HTTPS 公開して使う | ローカルの HTTP 配信で Chromium により確認 |
| iPad の「ファイル」アプリで ZIP を展開して HTML を開く | **未確認。動く前提にしない** |

## 6. ホーム画面・オフライン

- マニフェスト・Service Worker は実装していません。オフラインでは使えません。
- Safari の「ホーム画面に追加」は Safari の標準機能として使えますが、そこから開いた場合の動作と、Safari で開いた場合と保存データが共有されるかは確認していません。納品メッセージでは「毎回同じ方法で開く」よう案内しています。

## 7. 以前の保存データについて

- 体験版にする前に `https://mamochi-ai.github.io/coconara/` で入力した内容は、ブラウザ内の `katachi-awase:doc` に残っています（削除していません）。
- 購入者用ページは同じ保存場所を使うため、その端末・ブラウザで購入者用を開くと、以前の内容が表示されます。購入者の端末には関係ありません。
