# 配布と公開の手順・配布内容一覧

## 1. 構成

同じコード（`docs/`）から、版の設定（`docs/js/edition.js`）だけを変えて2つの版を作ります。

| | 公開体験版 | 購入者用 |
|---|---|---|
| 置き場所 | `docs/`（GitHub Pages で公開） | `build/`（`node scripts/build.mjs` で生成。git 管理外） |
| 確認画像 | 上下に「体験版・サンプル」の帯 | 帯なし |
| 開いたとき | 架空のサンプルを表示 | 空の状態（使い方からサンプル・新しい注文を選べる） |
| 保存場所（ブラウザ内） | `katachi-awase:trial:doc` | `katachi-awase:doc`（以前からの保存場所） |
| 購入ページへの案内 | `purchaseUrl` を設定したときだけ表示 | なし |

- 購入者用の配布物は `docs/` に置きません。`build/` は `.gitignore` に入っているため、リポジトリにも公開ページにも含まれません。
- **販売保護について**：静的なファイルは誰でも取得・改変できます。版の設定・保存場所の分離は、体験版と購入者用の表示とデータを分けるためのもので、購入者の認証やコピー防止の仕組みではありません。購入者用の URL を限られた人に伝える方法も、URL を知った人は誰でも開けるため、保護にはなりません。

## 2. 購入者用の作り方（作業者：開発環境を使う人）

```
node scripts/build.mjs
```

出力：

| ファイル | 内容 |
|---|---|
| `build/katachi-awase-buyer-<バージョン>.zip` | 購入者用の配布 ZIP |
| `build/katachi-awase/web/` | HTTPS で公開して使う一式（index.html, manual.html, css/, js/） |
| `build/katachi-awase/single/katachi-awase.html` | 1ファイル版（CSS と JavaScript を1つの HTML に収めたもの） |
| `build/katachi-awase/single/manual.html` | 使い方 |
| `build/katachi-awase/README.txt` | 購入者向けのはじめに（元は `product/buyer-README.txt`） |
| `build/katachi-awase/MANIFEST.txt` | 配布内容一覧（各ファイルの大きさと SHA-256） |

バージョンは `package.json` の `version`（現在 0.1.0）です。販売用のバージョン番号は未決定です。

| B. 購入者がパソコンで 1ファイル版を開く | `single/katachi-awase.html` をダブルクリック等で開く | なし | パソコン用ブラウザ（Chromium、file://）で、表示・サンプル・比較・画像作成・ダウンロードを確認。Safari・Edge・Windows は未確認 |
| C. 購入者が自分で `web/` を HTTPS で公開 | 静的ホスティングにアップロード | 購入者 | 一般にパソコンでの作業が必要。手順書は未作成 |
| D. iPad の「ファイル」アプリで ZIP を展開して HTML を開く | — | — | **未確認。動く前提にしない。** iPad のみの購入者には A を案内する |

iPad のみの購入者が使えるのは、現時点では **方式A（販売者が URL を提供）** だけを想定しています。方式A の公開作業が終わるまでは、「購入者が iPad で利用できる」状態ではありません。

### 方式A を GitHub Pages で行う場合の例（作業者：販売者）
1. 購入者用を置くための別のリポジトリを作る（体験版のリポジトリとは分ける）。
2. `build/katachi-awase/web/` の中身をそのリポジトリに置き、Settings → Pages で公開する。
3. 公開された URL を購入者に伝える。

注意：GitHub Pages のサイトは、リポジトリが非公開でも URL を知っていれば誰でも開けます（非公開リポジトリで Pages を使うには有料プランが必要な場合があります）。ほかの静的ホスティングでも同様です。

## 4. 公開体験版（作業者：販売者）

- `docs/` を GitHub Pages で公開しています（現在の公開 URL：https://mamochi-ai.github.io/coconara/ 。このブランチから配信されている場合、プッシュ後に更新されます。公開状態は変更していません）。
- 購入ページが決まったら、`docs/js/edition.js` の `TRIAL_EDITION.purchaseUrl` に URL を入れると、体験版の帯に「購入ページへ」のリンクが表示されます。未設定の間は表示しません。
- 以前にこの公開 URL で入力した内容は、以前の保存場所（`katachi-awase:doc`）に残っています。体験版は別の保存場所を使うため、体験版の画面には表示されません（削除はしていません）。
