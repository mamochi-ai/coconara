かたち合わせ　使い方

バッグのサイズや仕様変更を、ひと目で伝わる確認画像に。

ハンドメイドのバッグ作家が、お客様とのオーダー確認に使うツールです。この使い方は体験版・購入者用の両方に共通です（違いは「体験版について」に記載）。

できること

  • バッグの寸法（本体高さ・袋口幅・マチ・持ち手高さ）と、表地の色・裏地・内ポケットを入力すると、数値に合わせて模式図（正面図・側面図・内側図）が変わります。
  • お客様に送った内容を「変更前」として保存しておくと、その後に直した箇所を自動で比べ、変更点をオレンジ色と文字で示します。
  • お客様に送るための確認画像（PNG）を作れます。お客様用（かんたん）と作家用（詳細）を選べます。
  • 注文をいくつでも保存し、「注文一覧」で切り替えられます。注文を複製して、定番の寸法・仕様を使い回せます。
  • 入力内容はこの端末のブラウザに自動で保存されます。1件ずつ、または全注文をまとめてバックアップ（ファイルまたはテキスト）に書き出し、あとで追加できます。

お客様への送信機能はありません。保存した画像を、普段お使いのメッセージやメールに添付してください。

対応するバッグの形

底の角をつまんでマチを作る、シンプルな船底型のトートバッグ1種類です。ほかの形（巾着、ボストン、ファスナー付きの別形状など）には対応していません。

対応していないこと：型紙・裁断寸法・縫い代の計算、生地の必要量や価格の計算、製作できるかどうかの判断、お客様の承認の記録。

寸法を測る位置

すべて完成状態の寸法を cm で、小数第1位まで入力します。

本体高さ本体の底から袋口までの高さ。持ち手は含めません。
袋口幅袋口を平らにした状態の左右の幅。
マチ底の奥行き。袋口幅より小さい値にします。
持ち手高さ袋口から持ち手の頂点までの高さ。持ち手テープの全長ではありません。
底幅入力しません。袋口幅 − マチで自動計算します。この式は、このツールが対応する船底型トートの場合の関係で、すべてのバッグに当てはまるものではありません。

入力できる範囲（本体高さ 5〜80cm、袋口幅 5〜100cm、マチ 0〜40cm、持ち手高さ 3〜50cm）はツール上の目安で、その寸法で製作できることを保証するものではありません。空欄は「未入力」、0 は 0cm として区別します。

初回の確認画像を作る

  1. 体験版ではサンプルの注文が表示されています。購入者用で初めて開いたときは「使い方」の案内から 新しい注文を作る を選びます（あとからは 注文一覧 → 新しい注文を作る）。
  2. 「入力」で注文番号・寸法・表地の色・裏地・内ポケットを入力します。決まっていない項目は「未定」のままで構いません。
  3. 「図」で形と寸法を確認します。未入力・未定の項目は一覧に出て、押すとその入力欄へ移動します。
  4. 確認画像を作成 を押し、保存前プレビューで内容を確認します。
  5. 「お客様用（かんたん）」を選び、必要なら「側面図を含める」「内側図を含める」「注文メモを含める」を選びます。
  6. 画像を保存して、お客様に送ります。

未入力・未定の項目があっても画像は作れます（画像に「未入力・未定の項目」として記載されます）。寸法に誤りがある場合（例：マチが袋口幅以上）は画像を作れず、直す欄へ移動するボタンが表示されます。

変更前後を比較する

  1. お客様に送った内容のまま 変更前として保存 を押します。その時点の内容が「変更前（版1）」として残り、以降の編集は版2になります。
  2. お客様の希望に合わせて入力を直します。「比較」に、変更前と変更後の図が同じ縮尺で並び、変更点の一覧が表示されます。
  3. 件数は「仕様変更」（寸法・表地・裏地・ポケット）だけを数えます。注文メモや「お客様に確認したいこと」の変更は、別に「確認文の変更あり」などと表示します。
  4. 変更前と同じ値に戻すと、その項目の変更表示は消えます（40 と 40.0 は同じ値として扱います）。
  5. 確認画像を作成 で、変更前後を並べた画像を作ります。

自動保存と「変更前として保存」は別の操作です。入力内容は何もしなくても自動でこの端末に保存されます。「変更前として保存」は、比べる基準を記録するためのボタンです。

「変更前として保存」は、お客様の承認の記録ではありません。画像や画面にも「承認済み」などとは表示しません。

次の確認に進むときは 変更前を更新 を押します。それまでの変更前（例：版1）との比較は表示できなくなります。

画像を保存する

保存前プレビューの各画像の下に 画像を保存 拡大して確認 と、共有に対応した環境では 共有 が表示されます。

  • 画像を保存：画像ファイルのダウンロードを始めます。iPad の Safari では、ダウンロードしたファイルは通常「ファイル」アプリの「ダウンロード」に入ります（写真アプリには入りません）。
  • 写真に保存したいとき：拡大して確認 で画像を表示し、画像を長押しして、表示されたメニューの「"写真"に保存」を選びます。
  • 共有：ブラウザがファイルの共有に対応している場合だけ表示されます。共有をキャンセルしても問題はありません。
  • 内容が長いときは「図と変更点」「詳細」の複数の画像に分かれます。1枚ずつ保存してください。ファイル名には注文番号・版・用途・ページ番号が入ります。

「拡大して確認」の倍率を変えても、保存される画像の大きさや内容は変わりません。保存した画像は幅 2000 ピクセルです。

注文一覧（切り替え・複製・削除）

画面上部の 注文一覧 で、保存している注文を更新の新しい順に表示します。注文番号で検索できます。今開いている注文には「編集中」と表示されます。

  • 開く：注文の行を押します。切り替える前に、今の注文の入力は自動で保存されます。注文ごとに寸法・仕様・メモ・確認したいこと・変更前の内容・版番号・画像の出力設定が別々に保存され、混ざりません。
  • 新しい注文を作る：空の注文を追加して開きます。今ある注文は消えません。
  • 複製：行の その他 → 複製して新しい注文。寸法と仕様（表地の色・裏地と色・内ポケット）をコピーします。注文番号・メモ・確認したいこと・変更前の内容（比較履歴）は引き継がず、版1から始まります。元の注文は変わりません。よく作る仕様の注文を複製して使い回せます。
  • 削除：行の その他 → 削除。注文番号を表示して確認します。削除したあとは、このページを開いている間だけ 元に戻す で取り消せます。ページを閉じたり再読み込みしたりすると取り消せません。
  • 注文番号が同じ注文や、注文番号が未入力の注文があっても、それぞれ別の注文として保存されます（あとから注文番号を変えても、ほかの注文を上書きしません）。
  • 架空のサンプルは 注文一覧 → 架空のサンプルを追加 で、新しい注文として追加されます。今ある注文は消えません。

バックアップと追加

ブラウザに保存した内容は、消えることがあります（データの保存場所について）。区切りのよいところでバックアップを書き出してください。

  1. データ → 全注文をまとめて書き出す：保存しているすべての注文を1つのファイルに保存します（ファイル名に all-orders と件数が入ります）。注文一覧 からも書き出せます。
  2. データ → この注文を書き出す：今開いている注文だけを、変更前の内容・版番号ごと保存します（ファイル名に order と注文番号が入ります）。
  3. 読み込むときは データ → バックアップから追加 でファイルを選びます。ファイルの種類（1件用・全注文用・以前のバージョン）、読み込める注文の数、すでにある注文と重なるかを表示してから追加します。
  4. ファイルが使えない場合は「ファイルが使えない場合（テキストで書き出し・追加）」でテキストをコピーして保管し、貼り付けて テキストから追加 で読み込みます。

読み込んだ注文は、新しい注文として追加されます。今ある注文を書き換えたり、以前の状態に巻き戻したりはしません。変更前の内容と版番号はそのまま引き継ぎます。

同じファイルを2回読み込むと、同じ内容の注文が2件になります（確認画面でお知らせします）。不要なほうは注文一覧から削除してください。

壊れたファイル、新しいバージョンで作られたファイル、空き容量が足りないときは、何も追加せず、今ある注文はそのまま残ります。以前のバージョンで書き出した1件用のバックアップも読み込めます。

保存できないとき

  • 画面上部に「端末に保存できません」と出る場合：プライベートブラウズや、サイトデータを保存しない設定、空き容量の不足では保存できないことがあります。編集と画像の作成は続けられますが、ページを閉じると失われます。終わる前に必ず 全注文をまとめて書き出す でバックアップしてください。保存できない状態で注文を切り替えようとすると、確認が表示されます。
  • 画像を保存 で保存できない場合：拡大して確認 で画像を表示し、長押しで保存してください。
  • 「確認画像を作成できません」と出る場合：表示された項目（例：マチ）の値を直します。○○の欄へ移動 で入力欄へ移動できます。

データの保存場所について

  • 入力内容は、今使っている端末のブラウザの中だけに保存されます。サーバーへの送信や、ほかの端末との自動同期はしません。
  • iPad とスマートフォン、Safari とほかのブラウザでは、それぞれ別に保存されます。別の端末で続けるには、バックアップを書き出して復元してください。
  • ブラウザの履歴やサイトデータの削除、空き容量の不足、ブラウザの設定などにより、保存した内容が消えることがあります。
  • 体験版と購入者用は保存場所が別です。体験版で入力した内容は、購入者用には引き継がれません。
  • 以前のバージョン（注文1件だけを保存していた頃）の内容は、初めて開いたときに注文一覧の1件目として自動で引き継がれます。
  • 同じページを複数のタブで同時に開いて編集すると、あとから保存した内容で上書きされることがあります。1つのタブで使ってください。

ご注意

  • 模式図です。型紙・裁断図ではありません。図の形は模式的なもので、寸法は記載した数値を優先してください。
  • 色は目安です。画面や端末によって実際の生地の色とは異なります。
  • 持ち手とポケットの色・ポケットの大きさは、このツールでは指定しません（図では色を塗らずに示します）。内ポケットは「内側の片面中央に1個」として扱います。
  • 「未入力・未定の項目：なし」は入力項目の状況を示すもので、製作できること、入れたい物が収まることを示すものではありません。注文メモの内容（例：「A4が入る大きさ」）をツールが判断することはありません。

体験版について

  • 体験版は、架空のサンプルで入力・図・比較・拡大・画像保存を試すためのものです。
  • 体験版で作った確認画像には、上下に「体験版・サンプル」と入ります。
  • 体験版には、実際のお客様の情報を入力しないでください。
  • 購入者用は、確認画像に体験版の表示が入りません。機能は体験版と同じです。

この使い方は、ツールの現在の動作に合わせて記載しています。iPad の Safari での細かな表示（ダウンロード時の確認画面など）は、iOS のバージョンによって異なる場合があります。
