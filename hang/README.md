# HANG / ハング — ハンガーラックから服を選ぶサイト（サンプル）

架空のセレクトショップ「HANG / ハング」。一本の洋服ラックに掛かった服を、左右にかき分けて探し、
気になる一着をハンガーごと手前に引き出して見るためのサンプルです。サーバー・ログイン・有料 API は使いません。

## 起動

```
cd hang
npm install
npm run dev        # 開発サーバー（同じネットワークの iPad からも開けるよう --host 付き）
npm run build      # 型チェック → ../docs/hang/ に出力（GitHub Pages の /coconara/hang/ で公開）
npm run preview    # ビルド結果の確認
npm test           # 計算・コーデラックの単体テスト（Vitest）
npm run e2e        # ブラウザでの操作確認（ビルド後。Playwright + Chromium が必要）
```

出力は相対パス（`base: './'`）なので、どの静的ホスティングのどのパスにも置けます。

## 操作

| 操作 | 指・マウス | キーボード |
|---|---|---|
| 探す | ラックを左右にスワイプ／ドラッグ（離すと減速して近くの服に収まる）。PC は左右ボタン・トラックパッドの横スクロールも | ← → / Home / End |
| 選ぶ | 服をタップ（ハンガーごと手前に出る） | Enter / Space（中央の服） |
| 戻す | ×／「ラックへ戻す」／何もない所をタップ | Escape |
| コーデラック | 選んだ服の「コーデラックに掛ける」。下の「コーデラック」で引き出す | Tab で移動して操作 |

- スワイプの終わりや、動いているラックを止めるタップでは、服を選びません。
- 縦方向の指の動きはラックを動かしません。

## 構成

```
src/
  data/products.ts         商品データ（名前・カテゴリ・色・説明・画像・表示の調整値）
  components/Rack.tsx       ラック（指の操作・ばねの動き・描画。transform / opacity だけを更新）
  components/GarmentFigure.tsx  ハンガー＋服（一体で動く）。画像の読み込み失敗時は輪郭で代用
  components/DetailPanel.tsx    選んだ服の情報（横向きは右、縦長は下）
  components/CoordRack.tsx      コーデラック（最大3着。ハンガーに掛けて並べる）
  lib/rackMath.ts           配置・姿勢・移動・コーデラックの計算（単体テストあり）
  lib/storage.ts            localStorage（使えない環境でも操作は続く）
public/garments/*.svg      仮素材（独自に描いた服の SVG）
```

## 素材について

| 服 | 素材 |
|---|---|
| ウールメルトン チェスターコート | **写真素材**（提供された写真から背景を取り除いた `public/garments/chester-coat.webp`。木製ハンガーとフックが写っているため `hanger: 'none'`） |
| そのほか8着 | **仮素材**（このサンプル用に描いた SVG） |

写真の背景の取り除きには `tools/cutout-chester-coat.py`（OpenCV の GrabCut。コートの輪郭を手でなぞった線を手がかりにし、
細いフックは背景との差で取り出す）を使いました。別の写真では輪郭の座標を合わせ直す必要があります。
背景が単色・均一な写真や、最初から背景透過の画像なら、この作業は不要です。

### 仮素材（SVG）

`public/garments/` の SVG は、このサンプル用に描いた**仮素材**です（服だけを描き、ハンガーはコードで描いています）。

本番の素材（背景透過の PNG / WebP）に差し替えるときは、`public/garments/` に画像を置き、
`src/data/products.ts` の各商品を次のように調整します。

| 項目 | 意味 |
|---|---|
| `image` | 画像のパス（`public/` からの相対） |
| `hanger` | `'shoulder'`＝服だけの画像に肩用ハンガーを描く／`'clip'`＝クリップハンガーを描く／`'none'`＝**画像にハンガーが写っている**（コードでは描かない。二重にならない） |
| `anchor` | 画像の中でハンガーが掛かる点（0〜1）。`shoulder`/`clip` はバーの中央、`none` はフックの頂点 |
| `aspect` | 画像の 横÷縦（透過の余白を含む） |
| `scale` | 見かけの大きさ。余白の多い画像は大きく、丈の長い服は実際の長さに合わせる |
| `sway` | 揺れやすさ（重い服は小さく） |

他社サイトの商品画像は使わないでください。
